- `Fuerza suave` pasa a `Fuerza` y prioriza movimientos de fuerza general reales.
- Se añaden sentadilla controlada, zancada atrás corta, bisagra de cadera, sentadilla isométrica en pared, flexión inclinada, plancha alta y sentadilla + alcance.
- `Activarme` prioriza movimiento continuo y se diferencia de `Movilidad`.
- `Movilidad` conserva un carácter deliberadamente suave.
- Todas las rutinas siguen respetando silla/suelo y las zonas que el usuario prefiere no cargar.
- Cambiar ejercicio sigue usando la misma lógica de compatibilidad.
- Se amplían las regresiones automáticas de Move para validar identidad de enfoque y restricciones.
