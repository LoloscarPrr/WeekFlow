# WeekFlow Alpha 0.2.3

## OCR de horario más seguro

- Rechaza coincidencias parciales débiles del nombre configurado.
- Detecta más de una fila compatible y evita elegir una silenciosamente.
- Si la fila de horas queda demasiado lejos o incompleta, no inventa horarios.
- Los días reconstruidos con confianza media quedan marcados para revisión manual.
- Mantiene soporte para jornadas nocturnas y días libres 00:00.
- Android sube a versionCode 51 para actualizar sobre la build anterior.

Alcance canónico: SCH-07, SCH-08 y SCH-09.
