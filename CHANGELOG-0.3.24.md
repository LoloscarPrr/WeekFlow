# WeekFlow Alpha 0.3.24

## Selección manual en Biblioteca Move
- Los ejercicios compatibles quedan permitidos por defecto.
- El control de la tarjeta ahora es interactivo:
  - ✓ permitido para las rutinas;
  - — excluido por ti;
  - 🔒 no compatible con el perfil/equipo actual.
- La exclusión es persistente: un ejercicio quitado no vuelve a aparecer en generación, preview, progresión/regresión ni “Cambiar ejercicio”.
- “Muy fácil” solo progresa usando variantes que tú mantengas permitidas.
- “Difícil” y “Demasiado” tampoco pueden recuperar ejercicios que hayas excluido.
- “Restablecer” vuelve a permitir todos los ejercicios compatibles.

## Nivel y compatibilidad
- Principiante / Intermedio / Avanzado sigue definiendo qué ejercicios puedes habilitar.
- La selección manual no puede forzar ejercicios fuera de tu nivel, sin el equipo requerido o bloqueados por restricciones/impacto.
- Un ejercicio de intensidad alta puede dejarse permitido si tu perfil lo soporta; simplemente no aparecerá hasta una sesión cuya intensidad lo permita.

## Compatibilidad
- Perfiles anteriores cargan con todos los ejercicios permitidos.
- IDs antiguos o inexistentes se eliminan al persistir la selección.
