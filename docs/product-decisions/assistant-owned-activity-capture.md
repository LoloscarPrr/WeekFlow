# Activity capture belongs to Assistant

Decision: manual registration/classification of personal activities or “important moments” is removed from the current Semana flow.

Semana 0.2.x stays focused on the real work schedule: import, review, correction and confirmation. Personal commitments remain a future Assistant-owned capability, where natural-language input will write to the same canonical Brain/week state instead of creating a second planner.

The underlying important-moment data model is kept for compatibility and future Assistant use; the manual UI is not part of the current MVP.
