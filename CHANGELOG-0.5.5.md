# WeekFlow 0.5.5

## Consejo WeekFlow — cambios aprobados

- **Ahora primero:** la prioridad viva pasa a ser el primer contenido funcional de la pantalla y el encabezado responde directamente “Qué importa ahora”.
- **Move más flexible:** aparece “Dame una versión más corta” cuando una sesión puede reducirse; conserva objetivo, energía, intensidad adaptativa, equipo, cargas y restricciones, reduciendo solo el tiempo/volumen.
- **Disciplina de roadmap:** toda nueva spec debe declarar si pertenece a la fase actual (NOW) o al backlog antes de entrar a código.

## Deliberadamente fuera de este lote

Las ideas nuevas de Food, Rest, Brain/IA e Insights siguen documentadas para sus fases correspondientes. No se mezclaron con este release para evitar feature-creep.

## Compatibilidad

- Sin migraciones de persistencia.
- Sin cambios de esquema de datos.
- Se conservan historial y preferencias de Move.
- Se conservan lógica de jornada, salida real y reajuste de Ahora.

Specs: `WF-CORE-007`, `WF-NOW-001`, `WF-MOVE-008`
